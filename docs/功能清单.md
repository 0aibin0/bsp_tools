# DisplayTools 功能清单（v3.2.0 待定稿）

用途：**给老板/自己划范围用**。最后一列是我对「能不能砍」的判断，
直接在表里删行或者标掉就行，我按标记改代码。

图例：
- **保留** = 建议留着，砍了会影响日常用
- **可合并** = 和别的功能重复，可以并成一个入口
- **可删** = 独立成块但用得少，删掉不影响主流程
- **待定** = 你决定

## 我建议的「瘦身候选」（按性价比排）

1. **异常守护模块**（整块删）—— 你说 ESD 不做，剩下 6 类规则和「日志分析 + 现场包」有重叠
2. ~~**命令收藏模块** —— 和 Ctrl+K 命令面板重复，留一个就够~~
   → 已按另一条路处理（v3.2.13）：两处**共用一份数据**，命令面板当快捷入口，
   收藏页当管理界面，不再各存一套
3. **性能监控的趋势曲线** —— 表格已在，曲线是纯展示
4. **Panel 参数查询卡片** —— 6 个命令按钮，命令面板里都能搜到
5. **文件管理模块** —— Shell Tools 已有 push/pull，除非经常翻设备目录
6. **显示调试里的「ESD 重置」按钮** —— ESD 不做就删掉

砍掉 1+4+6 大概能少 2 个模块、少 1 个 Card，界面更紧凑；
砍掉 5 再少一个模块。剩下的都是「调试屏体必用」的骨架。
